## 2. Why did your work email end up in GitHub?

This is a Git configuration inheritance issue.

Git commits contain two attribution fields: Author and Committer. When Claude made the commits, Git used the identity already configured on your Windows machine.

That does not mean your application is connected to your employer's infrastructure.

However, your current Git history includes that unwanted historical attribution, and I agree it should be corrected.

### Fix all future Git commits immediately

I recommend GitHub's private noreply email.

Find the exact address under [GitHub → Settings → Emails](https://github.com/settings/emails).

Then run this in Windows PowerShell:

```
cd "$HOME\Projects\approval-platform"

# Set personal identity for THIS repository only
git config --local user.name "Austin Ardizzone"

git config --local user.email "YOUR_GITHUB_NOREPLY_ADDRESS"

# Confirm
git config --local --list --show-origin
```

This stops future commits from inheriting the unwanted work identity.

Important: It doesn't retroactively remove the old email from already-pushed commits.
